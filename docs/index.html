03 / CONCURRENCY

兩個護理站同時領最後幾瓶酒精

酒精剩 8 瓶，A、B 同一瞬間各出庫 6 瓶。如果只是「讀 → 判斷 → 寫」，兩個請求都讀到 8，兩個都成功，帳上剩 2、實際被領走 12。

沒有鎖交易＋列鎖
B 讀到8（舊值）2（等 A 提交後）
結果兩筆都 201A 201、B 422
帳實帳上 2，實際超賣 4 瓶帳上 2，架上 2

SQLite 會鎖整個資料庫的寫入，MySQL InnoDB 是真正的列鎖。同一段程式在兩種資料庫下結果都正確。

在 Demo 裡看動畫對照 
public function outbound(Product $product, int $qty, ...): StockMovement
{
    return DB::transaction(function () use (...) {
        // SELECT ... FOR UPDATE：其他交易要等這裡提交
        $locked = Product::query()
            ->lockForUpdate()
            ->findOrFail($product->id);
        $before = $locked->quantity;

        if ($qty > $before) {
            // 丟例外 → 交易回滾，庫存不變
            throw InsufficientStockException::for(
                $locked->sku, $before, $qty);
        }

        $locked->quantity = $before - $qty;
        $locked->save();

        return StockMovement::query()->create([
            'type' => 'out', 'quantity' => $qty,
            'before_qty' => $before,
            'after_qty'  => $locked->quantity, ...
        ]);
    });
}

04 / SECURITY

安全對照

風險作法位置
SQL Injection全部走 Eloquent／Query Builder（底層是 PDO Prepared Statements），不拼接 SQLapp/Models
XSSBlade {{ }} 自動跳脫；不對使用者輸入用 {!! !!}resources/views
CSRF所有表單帶 @csrf，web 中介層驗證layouts/app.blade.php
密碼User 的 hashed cast（bcrypt），不存明文Models/User.php
API Token資料庫只存 SHA-256；註冊時只顯示一次VerifyApiToken.php
輸入驗證Form Request 集中定義規則，網頁和 API 共用app/Http/Requests

06 / INSTALL

在自己電腦跑起來

  1. 準備環境：PHP 8.2 以上與 Composer。Windows 建議裝 Laravel Herd，PHP 和 Composer 都包好了。
  2. 取得程式並安裝套件 
    git clone https://github.com/Tai-Ju/php-inventory-wms
cd php-inventory-wms/inventory-wms
copy .env.example .env
composer install
php artisan key:generate
  3. 建立資料表與示範資料（預設 SQLite，免裝資料庫） 
    php artisan migrate --seed
php artisan test
  4. 啟動，開 http://127.0.0.1:8000，帳號 warehouse@example.com／password 
    php artisan serve
Windows 小提醒
  • 也可以直接點兩下 inventory-wms/setup.bat，一次完成上面所有步驟。
  • artisan serve 出現 Failed to listen … (reason: ?) 時，改在 public 資料夾用 php -S 啟動（指令見 README）。
  • 專案不要放在 OneDrive 同步資料夾，SQLite 檔可能被鎖住。
