# 畫面截圖（GitHub README 用）

本機尚未安裝 PHP，無法在這裡直接產生成品截圖。專案跑起來後請截這四張，放到本資料夾：

1. `01-dashboard.png` — 庫存看板（含低庫存數字）
2. `02-products.png` — 商品卡片列表
3. `03-stock-out.png` — 出庫表單
4. `04-low-stock.png` — 低庫存篩選或商品明細

然後在根目錄 README 用 Markdown 嵌入：

```markdown
![看板](docs/screenshots/01-dashboard.png)
```
